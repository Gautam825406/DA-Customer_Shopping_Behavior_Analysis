📊 Customer Shopping Behavior Analysis & Dashboard
📌 Project Overview

This project focuses on analyzing customer shopping behavior using transactional retail data and presenting actionable insights through an interactive Power BI dashboard.
The goal is to help businesses understand customer preferences, purchasing patterns, revenue drivers, and subscription behavior to support data-driven decision-making.

The analysis combines Python, SQL (PostgreSQL), and Power BI, following an end-to-end data analytics workflow — from raw data to business recommendations.
